# 🎉 게임 모음집 (Game Collection)

웹 브라우저에서 바로 즐기는 파티 게임 모음집입니다. 설치·빌드 없이 작동합니다.

## 실행 방법
`index.html` 파일을 **더블클릭**해서 브라우저로 열면 끝입니다.

> 발표/큰 화면용으로 좋습니다. (F11 = 전체화면)

## 게임 구성
첫 화면에서 두 게임으로 나뉩니다.

### ⚡ 스피드 퀴즈
- 16개 카테고리, 각 15문제
- 카테고리 선택 → 타이머(기본 60초) 안에 정답 맞히기
- **정답! ✓** 버튼 = +1점 / **패스 ✕** = 다음 문제 / **정답 보기** = 답 공개
- 키보드 단축키: `→` 또는 `O` = 정답, `←` 또는 `X` = 패스, `Space` = 정답 보기
- 시간이 끝나거나 15문제를 다 풀면 결과 화면

### 👨‍👩‍👧‍👦 Family Feud
- 설문 답변 맞히기, 두 팀 점수 대결
- 답변 칸 클릭 = 공개 + 라운드 합계에 점수 적립 (다시 누르면 취소)
- **스트라이크 ✕** 3개, **전체 공개**, **이전/다음 라운드**
- **+ 라운드 점수** = 현재 라운드 합계를 해당 팀 점수로 전달
- 팀 이름은 직접 입력해서 바꿀 수 있어요

## 문제 내용 수정 (가장 중요!)
모든 문제는 `data/` 폴더의 파일만 고치면 됩니다. 코드는 건드릴 필요 없습니다.

### 스피드 퀴즈 — `data/speedquiz.js`
```js
"음식1": [
  { q: "둥근 빵 사이에 패티와 채소를 넣은 음식은?", a: "햄버거" },
  { q: "여기에 문제", a: "여기에 정답" },
  // ... 15개
],
```
- `placeholder("이름")` 으로 되어 있는 카테고리는 아직 예시 문제이니
  위 형식처럼 직접 15개를 채워 넣으면 됩니다.
- 이미 채워진 예시 카테고리: 교회 / 성경인물1 / 음식1 / 국가1 / 애니메이션 / 명대사

### Family Feud — `data/familyfeud.js`
```js
{
  question: "‘여름’ 하면 떠오르는 것은?",
  answers: [
    { text: "바다/해수욕장", points: 30 },
    { text: "수박", points: 22 },
    // 답변은 점수 높은 순으로
  ],
},
```

## 폴더 구조
```
JUST/
├─ index.html          # 모든 화면(허브/퀴즈/피드)
├─ css/style.css       # 디자인
├─ js/
│  ├─ app.js           # 화면 전환(라우팅)
│  ├─ speedquiz.js     # 스피드 퀴즈 로직
│  └─ familyfeud.js    # Family Feud 로직
└─ data/
   ├─ speedquiz.js     # ← 퀴즈 문제 (여기 수정)
   └─ familyfeud.js    # ← Feud 문항 (여기 수정)
```

## 게임 더 추가하기
허브(`index.html`의 `screen-hub`)에 카드를 하나 더 넣고, 새 `screen-*` 섹션과
`js/` 로직 파일을 추가하면 모음집에 새 게임을 계속 붙일 수 있습니다.
